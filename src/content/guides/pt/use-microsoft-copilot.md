## O que vai aprender

Neste guia, vai aprender a usar o Microsoft Copilot, o assistente de IA gratuito da Microsoft. Pode responder a perguntas, ajudar a escrever, resumir textos longos e pesquisar na Internet informacoes atuais. Pode usa-lo no navegador web, no navegador Edge ou num computador Windows.

## O que precisa

- Um computador, tablet ou telemovel com acesso a Internet
- Um navegador web (qualquer navegador funciona, mas o Edge tem o Copilot integrado)
- Uma conta Microsoft e opcional mas recomendada para guardar conversas

## Passo a passo

### Passo 1: Abrir o Microsoft Copilot

Abra o seu navegador web e va a **copilot.microsoft.com**. Vai ver a interface do Copilot com uma caixa de texto onde pode comecar a fazer perguntas.

Pode comecar a usar o Copilot imediatamente sem criar conta. No entanto, se iniciar sessao com uma conta Microsoft, as suas conversas ficam guardadas.

### Passo 2: Iniciar sessao (opcional mas recomendado)

Se tiver uma conta Microsoft (a mesma que usa para o Outlook, Hotmail ou Windows), clique em **Iniciar sessao** no canto superior direito. Isto permite ao Copilot guardar as suas conversas e dar-lhe mais funcionalidades.

Se nao tiver uma conta Microsoft, pode usar o Copilot sem iniciar sessao.

### Passo 3: Fazer a sua primeira pergunta

Na caixa de texto, escreva uma pergunta ou pedido. Por exemplo:

- "O que e a tensao arterial e porque e importante?"
- "Ajuda-me a escrever um email para reagendar uma reuniao"
- "O que aconteceu nas noticias hoje?"

Carregue em **Enter** ou toque no botao de enviar. O Copilot vai pesquisar na Internet se necessario e escrever a sua resposta, frequentemente com ligacoes para fontes que pode verificar.

### Passo 4: Usar para escrever e resumir

O Copilot e muito bom a ajudar a escrever. Experimente:

- "Escreve uma mensagem curta de aniversario para a minha irma"
- "Resume os pontos principais deste artigo: [cole o texto]"
- "Reescreve este paragrafo em linguagem mais simples: [cole o texto]"

Pode continuar a pedir para ajustar o tom, o comprimento ou o estilo ate ficar satisfeito com o resultado.

### Passo 5: Experimentar o Copilot no navegador Edge

Se usar o Microsoft Edge como navegador web, o Copilot esta integrado. Procure o icone do Copilot no canto superior direito do navegador Edge (parece um pequeno circulo azul). Clique nele para abrir uma barra lateral onde pode:

- Fazer perguntas sobre o site que esta a ver
- Resumir um artigo longo que esta a ler
- Obter ajuda com formularios ou documentos na pagina

### Passo 6: Comecar uma nova conversa

Quando quiser mudar de tema, clique no botao **Novo tema** ou **Novo chat**. Isto inicia uma conversa nova. As conversas anteriores ficam disponiveis no seu historico se tiver sessao iniciada.

## Dicas uteis

- **O Copilot pode pesquisar na Internet.** Ao contrario da versao gratuita do ChatGPT, o Copilot pode procurar informacoes atuais online. Isto torna-o melhor para noticias recentes, precos atuais ou factos atualizados.
- **Verifique as fontes.** O Copilot frequentemente fornece ligacoes para os sites onde encontrou a informacao. Clique nessas ligacoes para verificar a informacao diretamente.
- **Use no Windows.** No Windows 11, pode abrir o Copilot premindo a tecla Windows + C no teclado, ou clicando no icone do Copilot na barra de tarefas.
- **Como com toda a IA, verifique respostas importantes.** O Copilot e util mas nem sempre esta correto. Para decisoes medicas, juridicas ou financeiras, consulte sempre um profissional.
