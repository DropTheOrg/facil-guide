## Ce que vous allez apprendre

Dans ce guide, vous allez apprendre a utiliser Microsoft Copilot, l'assistant IA gratuit de Microsoft. Il peut repondre aux questions, vous aider a ecrire, resumer de longs textes et chercher sur Internet des informations actuelles. Vous pouvez l'utiliser dans votre navigateur web, dans le navigateur Edge ou sur un ordinateur Windows.

## Ce dont vous avez besoin

- Un ordinateur, une tablette ou un smartphone avec acces a Internet
- Un navigateur web (tout navigateur fonctionne, mais Edge a Copilot integre)
- Un compte Microsoft est optionnel mais recommande pour sauvegarder les conversations

## Instructions etape par etape

### Etape 1 : Ouvrir Microsoft Copilot

Ouvrez votre navigateur web et allez sur **copilot.microsoft.com**. Vous verrez l'interface de Copilot avec une zone de texte ou vous pouvez commencer a poser des questions.

Vous pouvez commencer a utiliser Copilot immediatement sans creer de compte. Cependant, si vous vous connectez avec un compte Microsoft, vos conversations seront sauvegardees.

### Etape 2 : Se connecter (optionnel mais recommande)

Si vous avez un compte Microsoft (le meme que vous utilisez pour Outlook, Hotmail ou Windows), cliquez sur **Se connecter** en haut a droite. Cela permet a Copilot de sauvegarder vos conversations et de vous offrir plus de fonctionnalites.

Si vous n'avez pas de compte Microsoft, vous pouvez quand meme utiliser Copilot sans vous connecter.

### Etape 3 : Poser votre premiere question

Dans la zone de texte, tapez une question ou une demande. Par exemple :

- "Qu'est-ce que la tension arterielle et pourquoi est-ce important ?"
- "Aide-moi a ecrire un email pour reporter une reunion"
- "Que s'est-il passe dans les nouvelles aujourd'hui ?"

Appuyez sur **Entree** ou touchez le bouton d'envoi. Copilot cherchera sur Internet si necessaire et ecrira sa reponse, souvent avec des liens vers des sources que vous pouvez verifier.

### Etape 4 : L'utiliser pour ecrire et resumer

Copilot est tres bon pour aider a ecrire. Essayez :

- "Ecris un court message d'anniversaire pour ma soeur"
- "Resume les points principaux de cet article : [collez le texte]"
- "Reecris ce paragraphe en langage plus simple : [collez le texte]"

Vous pouvez continuer a lui demander d'ajuster le ton, la longueur ou le style jusqu'a ce que vous soyez satisfait du resultat.

### Etape 5 : Essayer Copilot dans le navigateur Edge

Si vous utilisez Microsoft Edge comme navigateur, Copilot est integre. Cherchez l'icone Copilot en haut a droite du navigateur Edge (un petit cercle bleu). Cliquez dessus pour ouvrir un panneau lateral ou vous pouvez :

- Poser des questions sur le site que vous consultez
- Resumer un long article que vous lisez
- Obtenir de l'aide avec les formulaires ou documents de la page

### Etape 6 : Commencer une nouvelle conversation

Quand vous voulez changer de sujet, cliquez sur le bouton **Nouveau sujet** ou **Nouveau chat**. Cela demarre une conversation neuve. Les conversations precedentes sont disponibles dans votre historique si vous etes connecte.

## Conseils

- **Copilot peut chercher sur Internet.** Contrairement a la version gratuite de ChatGPT, Copilot peut rechercher des informations actuelles en ligne. C'est mieux pour les actualites recentes, les prix actuels ou les faits a jour.
- **Verifiez les sources.** Copilot fournit souvent des liens vers les sites ou il a trouve ses informations. Cliquez sur ces liens pour verifier directement.
- **Utilisez-le sur Windows.** Sur Windows 11, vous pouvez ouvrir Copilot en appuyant sur la touche Windows + C, ou en cliquant sur l'icone Copilot dans la barre des taches.
- **Comme pour toute IA, verifiez les reponses importantes.** Copilot est utile mais pas toujours correct. Pour les decisions medicales, juridiques ou financieres, consultez toujours un professionnel.
