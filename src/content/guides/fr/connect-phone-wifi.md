## Ce que vous allez apprendre

Dans ce guide, vous allez apprendre a connecter votre telephone Android a un reseau Wi-Fi. Le Wi-Fi permet a votre telephone d'utiliser internet grace a une connexion sans fil chez vous, dans un cafe ou partout ou il est disponible. Utiliser le Wi-Fi au lieu des donnees mobiles est souvent plus rapide et preserve votre forfait de donnees.

## Ce dont vous avez besoin

- Un telephone Android
- Un reseau Wi-Fi a proximite (chez vous, chez un ami ou dans un lieu public)
- Le mot de passe Wi-Fi (si le reseau est protege)

## Les etapes

### Etape 1 : Ouvrir les Reglages

Trouvez l'application **Reglages** sur votre telephone. Elle ressemble generalement a un petit engrenage ou une roue dentee. Appuyez dessus pour l'ouvrir. Sur la plupart des telephones Android, vous pouvez aussi faire glisser vers le bas depuis le haut de l'ecran et appuyer sur l'icone d'engrenage en haut a droite.

### Etape 2 : Appuyer sur Wi-Fi ou Reseau et internet

Dans le menu Reglages, cherchez **Wi-Fi** ou **Reseau et internet** (le nom exact varie legerement selon la marque de votre telephone). Appuyez dessus. Si vous voyez Reseau et internet, appuyez d'abord dessus, puis appuyez sur **Wi-Fi**.

### Etape 3 : Activer le Wi-Fi

Si le Wi-Fi est desactive, vous verrez un interrupteur en haut de l'ecran. Appuyez sur l'interrupteur pour l'**activer**. Il changera de couleur ou glissera vers la droite pour montrer qu'il est actif. Votre telephone va maintenant commencer a chercher les reseaux Wi-Fi disponibles a proximite.

### Etape 4 : Selectionner votre reseau Wi-Fi

Apres quelques secondes, vous verrez une liste des reseaux Wi-Fi disponibles. Cherchez le nom de votre reseau domestique (ou du reseau que vous souhaitez rejoindre). Le nom est generalement imprime sur une etiquette sur votre routeur Wi-Fi. Appuyez sur le nom du reseau pour le selectionner.

### Etape 5 : Entrer le mot de passe et se connecter

Une fenetre apparaitra pour vous demander le mot de passe Wi-Fi. Tapez le mot de passe soigneusement avec le clavier qui apparait. Les mots de passe Wi-Fi sont sensibles a la casse, ce qui signifie que les majuscules et les minuscules comptent. Apres avoir tape le mot de passe, appuyez sur **Connecter**. Apres quelques secondes, vous verrez le mot "Connecte" sous le nom du reseau. Vous etes maintenant en Wi-Fi.

## Conseils utiles

- **Verifiez le symbole Wi-Fi** : Quand vous etes connecte, un petit symbole Wi-Fi (en forme d'eventail ou d'ondes) apparaitra en haut de votre ecran. Cela confirme que vous utilisez le Wi-Fi.
- **Votre telephone se souvient des reseaux** : Une fois connecte a un reseau Wi-Fi, votre telephone s'en souviendra et se connectera automatiquement la prochaine fois que vous serez a proximite. Vous n'aurez pas besoin de retaper le mot de passe.
- **Demandez poliment le mot de passe** : Dans un cafe ou chez un ami, c'est tout a fait normal de demander "Quel est le mot de passe du Wi-Fi ?" On vous le donnera volontiers.
- **Oublier un reseau si necessaire** : Si vous avez des problemes avec un reseau Wi-Fi, vous pouvez l'"oublier" en appuyant sur le nom du reseau, puis en appuyant sur **Oublier** ou sur l'icone d'engrenage puis Oublier. Essayez ensuite de vous reconnecter depuis le debut.

*Pour un depannage detaille, consultez la page d'assistance du fabricant de votre appareil ou testez votre vitesse de connexion sur [Speedtest d'Ookla](https://www.speedtest.net).*
