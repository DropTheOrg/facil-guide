## Ce que vous allez apprendre

Dans ce guide, vous allez apprendre a configurer l'authentification a deux facteurs (souvent appelee 2FA) sur votre iPhone. L'authentification a deux facteurs, c'est comme ajouter un deuxieme verrou a votre porte d'entree. Meme si quelqu'un connait votre mot de passe, il a besoin d'un code special envoye sur votre telephone pour entrer. C'est l'un des moyens les plus simples et les plus efficaces de proteger vos comptes.

## Ce dont vous avez besoin

- Un iPhone avec iOS 15 ou plus recent
- Un compte que vous souhaitez proteger (comme votre identifiant Apple, compte Google ou e-mail)
- Quelques minutes de votre temps

## Les etapes

### Etape 1 : Comprendre ce que fait l'authentification a deux facteurs

Quand vous vous connectez a un compte avec seulement un mot de passe, toute personne qui connait ce mot de passe peut entrer. L'authentification a deux facteurs ajoute une deuxieme etape : apres avoir entre votre mot de passe, vous devez aussi entrer un code court envoye sur votre telephone ou genere par une application. Cela signifie que seul vous -- la personne qui a le telephone en main -- pouvez acceder au compte.

### Etape 2 : Ouvrir les Reglages de votre iPhone

Allez sur votre ecran d'accueil et appuyez sur l'application **Reglages**. Elle a une icone grise qui ressemble a des engrenages. C'est ici que vous allez configurer l'authentification a deux facteurs pour votre identifiant Apple, qui protege votre iCloud, l'App Store et les autres services Apple.

### Etape 3 : Appuyer sur votre nom en haut

Tout en haut de l'ecran Reglages, vous verrez votre nom et votre photo (ou vos initiales). Appuyez dessus. Cela vous amene aux reglages de votre **identifiant Apple**, ou vous gerez la securite de votre compte.

### Etape 4 : Aller dans Connexion et securite

Appuyez sur **Connexion et securite**. Cette section controle la maniere dont vous vous connectez a votre compte Apple. C'est ici que vous trouverez l'option pour activer l'authentification a deux facteurs.

### Etape 5 : Activer l'authentification a deux facteurs

Appuyez sur **Authentification a deux facteurs**. Si elle n'est pas encore activee, vous verrez une option pour l'activer. Appuyez sur **Continuer** et suivez les instructions a l'ecran. Votre iPhone peut vous demander de confirmer votre numero de telephone. C'est le numero ou Apple enverra les codes de verification.

### Etape 6 : Verifier avec un code

Apple enverra un code de verification a votre numero de telephone par SMS. Entrez ce code quand on vous le demande. Une fois verifie, l'authentification a deux facteurs est active. Desormais, chaque fois que vous (ou quelqu'un d'autre) essayez de vous connecter a votre compte Apple depuis un nouvel appareil, un code sera envoye sur vos appareils de confiance.

## Conseils utiles

- **Conservez vos codes de secours** : Quand un service vous donne des codes de recuperation ou de secours, notez-les sur papier et gardez-les dans un endroit sur chez vous. Ne les conservez pas uniquement sur votre telephone.
- **Commencez par vos comptes les plus importants** : Protegez d'abord votre e-mail et vos comptes bancaires. Ce sont les plus precieux a securiser.
- **Vous n'aurez pas besoin du code a chaque fois** : Sur les appareils que vous utilisez regulierement, vous ne devez generalement entrer le code qu'une seule fois. Votre telephone se souvient qu'il s'agit d'un appareil de confiance.
